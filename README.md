## 👩‍💻 Sobre o projeto

O Portfólio Profissional é um site desenvolvido para apresentar meu perfil, formação acadêmica, tecnologias estudadas e projetos realizados na área de desenvolvimento de sistemas.

O objetivo é reunir minhas informações profissionais e acadêmicas em um único espaço, demonstrando minha trajetória e evolução na área de tecnologia.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e personalização do layout.
- **Bootstrap 5:** componentes visuais e responsividade.
- **JavaScript:** funcionamento dos componentes interativos do Bootstrap.
- **Devicon:** biblioteca de ícones das tecnologias.
- **GitHub:** versionamento e hospedagem do projeto.

## ✨ Funcionalidades

- 👤 Apresentação do perfil profissional.
- 🎓 Seção de formação acadêmica.
- 💻 Cards com tecnologias e ferramentas.
- 📂 Apresentação de projetos desenvolvidos.
- 📧 Links para contato, GitHub e LinkedIn.
- 🖼️ Carrossel de imagens.
- 📱 Layout responsivo para diferentes dispositivos.
- 🎨 Personalização visual com tons de roxo.
- 🪄 Efeito hover nos cards.

## 🆕 Recurso novo adicionado

Foi adicionada uma seção de **Formação**, que apresenta minha trajetória acadêmica em dois cards:

- 🧠 Psicologia – graduação concluída em 2021.
- 💻 Desenvolvimento de Sistemas – ETEC, curso em andamento.

Cada card apresenta o nome da formação, uma breve descrição e um selo indicando sua situação.

Também foram realizadas melhorias no design, incluindo uma paleta de cores personalizada, efeito hover nos cards e um novo link de acesso à seção Formação no menu principal.

## ⚙️ Como o recurso foi implementado

A nova seção foi desenvolvida utilizando HTML5 e Bootstrap 5.

Foi criada uma estrutura `<section>` com o identificador `formacao`, contendo um `container`, uma `row` e dois cards responsivos.

Para complementar a apresentação, foram utilizadas classes do Bootstrap, como `card`, `card-body`, `badge`, `shadow-sm` e `rounded-4`.

O efeito hover foi implementado com CSS, utilizando `transition` e `transform: translateY(-3px)` para criar um movimento suave nos cards ao passar o mouse.

A personalização das cores foi realizada no bloco `<style>`, substituindo as cores padrão por tons de roxo.

## 🚀 Como visualizar o projeto

Não é necessário instalar programas ou executar comandos para visualizar o portfólio.

1. Acesse o link do site publicado.
2. Navegue pelas seções utilizando o menu principal.
3. Visualize o perfil, a formação, as tecnologias e os projetos.
4. Acesse os links disponíveis na seção de contato.
